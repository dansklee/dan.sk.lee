# Decisions

One file per decision, named `YYYY-MM-DD-short-slug.md`, dated from when the
decision was made rather than when it was written down.

Records are proposed by the [decision log](../.github/workflows/decision-log.md)
as pull requests and land here once you've reviewed them. You can also write
one by hand — the format is in
[the policy](../.github/policies/decision-record-policy.md).

**This directory is append-only.** When a decision is reversed, the new record
says which file it supersedes and both stay. Being able to see that you changed
your mind — and what you believed when you didn't — is the reason the log
exists at all.

The section that earns its keep is **What we believed at the time**. That's
what you check when a decision starts looking wrong, and it's what the
[red team](../.github/workflows/red-team.md) attacks while changing course is
still cheap.
